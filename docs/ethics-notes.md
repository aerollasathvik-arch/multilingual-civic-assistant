# Ethics notes (Week 1 pre-screen) - status: draft, not yet submitted

**Needs approval:** the user study involves human participants, possibly from groups with limited English
proficiency, so it must go through the college's research ethics process before any recruitment.
Retrieval and answer evaluation use only public government pages and need no participant data.

Points the application must cover:
- **Informed consent** in the participant's language, plain wording, right to withdraw.
- **No personal circumstances collected.** Participants use set scenarios ("Imagine your landlord...")
  rather than their real housing, health or immigration situation.
- **Data handling:** no names stored with responses; questions typed during sessions are not sent to a
  third-party LLM API unless the participant has been told and agreed.
- **Harm from wrong answers:** the prototype is labelled as a research tool, every answer links to the
  official page, and urgent health questions are always pointed to NHS 111 / 999.
- **Interpreting support:** if a participant cannot read the consent form in English, a translated form
  is provided; translations to be checked by a native speaker.

Action for the student: confirm the college's ethics form and deadline with the supervisor, then submit
(task T04 / T33 in the plan).
